## Fonctionnalités

- écran de connexion ;
- consultation du solde ;
- dépôts et retraits simulés ;
- historique des opérations ;
- conversion de devises ;
- interface responsive.

## Lancer localement

Aucune dépendance n'est nécessaire. Ouvrir index.html ou servir le dossier avec un serveur statique :

    python -m http.server 8000

Ouvrir ensuite http://localhost:8000.

Projet de formation consacré au DOM, aux événements JavaScript et à la conception d'une interface métier. Les opérations sont uniquement simulées côté navigateur.
